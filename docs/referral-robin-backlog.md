# Referral Robin — Feature Backlog

Source of truth for feature ideas, their status, and a dated session log of
what's actually shipped. Lives in the repo (not `/mnt/user-data/...` or
anywhere outside git) so it's readable and editable directly — update it
with normal edits whenever a feature ships or a session needs a log entry.

Conventions:
- Ideas are numbered (`#1`, `#2`, ...) and never renumbered once assigned,
  even if one is later dropped — so old session log entries referencing an
  idea by number stay accurate.
- Each idea has a `Status:` line (`not started` / `in progress` / `shipped`
  / `dropped`), updated in place as it moves.
- The Session Log at the bottom is append-only, newest last, dated entries
  noting what was actually done in a given session — not a restatement of
  the idea list, but a record of real work (batches added, bugs fixed,
  decisions made).
